# Admin Community Integration & Sidebar Labels Clarification Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate the Community Discussions & AI Bot view into the Admin Control Center with dedicated admin routing, and clarify client/admin sidebar labels to eliminate confusion between public community discussions and private support helpdesk tickets.

**Architecture:** 
1. Create a dedicated `/admin/community` page that embeds the `CommunityBoard` with admin moderation context and metrics.
2. Wire `Community Discussions` into `AdminSidebar` under `Commercial & Governance` alongside `Support Tickets`.
3. Update `ClientSidebar` labels to explicitly distinguish between public peer discussions (`Advocate Community & AI Bot` with `Public` badge) and private chamber assistance (`Helpdesk & Support` / `Chamber Support`).
4. Add thread deletion UI in `ThreadDrawer` for admins and authors backed by the existing `DELETE /api/community/threads/[id]` API.

**Tech Stack:** Next.js 15 (App Router), React 19, Lucide React, Tailwind CSS, TypeScript.
